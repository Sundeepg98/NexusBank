## Common Issues & Fixes

| Issue | Solution |
|-------|----------|
| "Invalid Date" on transactions | Convert Neo4j datetime to ISO string in backend |
| Account numbers not generating | Use `substring(randomUUID(), 0, 12)` instead of APOC |
| Neo4j integers as objects | Use `neo4j.isInt().toNumber()` |
| Import path errors | Use relative paths like `../../services/api` |

### Angular 19+ Concepts Implemented
- Signals: `signal()`, `computed()`, `effect()` for reactive state
- `@if`/`@for`/`@defer` control flow (replaces `*ngIf`/`*ngFor`)
- `ChangeDetectionStrategy.OnPush` for performance
- `@Input()`/`@Output()` with signals
- `@ViewChild` for component references
- Content projection with `ng-content`
- Route Resolver for data preloading
- HTTP Interceptors (auth, error handling)
- Angular Animations (`@fadeIn`, `@slideIn`)
- Custom Pipes (`CurrencyPipe`, `DateFormatPipe`)
- Skeleton Loader Component
- FormArray for dynamic batch transfers
