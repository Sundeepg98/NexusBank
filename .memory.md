# NexusBank Developer Memory

## Quick Commands

```bash
# Frontend
cd frontend && npm start          # Dev server (port 4200)
cd frontend && npm run build     # Production build

# Backend
cd backend && npm start          # API server (port 3000)
```

## E2E Testing with OTP

OTP is logged to console in format: `[OTP] {code} | {purpose} | {userId}`

```bash
# 1. Start servers
cd backend && npm start
cd frontend && npm start

# 2. Generate OTP via UI or API
# POST /api/transactions/generate-otp with auth token

# 3. Get OTP from backend console logs
# Format: [OTP] 123456 | transfer | user-id

# Or query Neo4j directly:
cd backend && node get-otp.js <email>
```

## Rate Limiting

- **Test mode:** Rate limits set to 100 req (skipped when NODE_ENV=test)
- **Production:** 3 req/min for OTP generation, 5 req/15min for verification
- Set `NODE_ENV=test` in backend/.env for E2E testing

## Account Number Format

- Format: UUID-like with dash (e.g., `7429c59e-b37`)
- Validation: `/^[A-Za-z0-9-]{6,20}$/` (both frontend and backend)

## Neo4j Connection
- URI: `neo4j+s://f3ed3ed9.databases.neo4j.io`
- Username: `f3ed3ed9` (instance ID, NOT "neo4j")

## Common Issues & Fixes

| Issue | Solution |
|-------|----------|
| "Invalid Date" on transactions | Convert Neo4j datetime to ISO string in backend |
| Account numbers not generating | Use `substring(randomUUID(), 0, 12)` instead of APOC |
| Neo4j integers as objects | Use `neo4j.isInt().toNumber()` |
| Import path errors | Use relative paths like `../../services/api` |
| Rate limiting blocking tests | Set NODE_ENV=test in .env |

## Security Notes
- OTP uses `crypto.randomInt(100000, 999999)` (cryptographically secure)
- OTP persisted to Neo4j with 5-minute expiry
- OTP deleted after successful verification
- Passwords hashed with bcrypt
- Token blacklisting stored in Neo4j
