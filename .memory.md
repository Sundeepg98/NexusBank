# NexusBank Project Memory

## Project Overview
Full-stack netbanking application with Angular 19 frontend and Node.js/Express backend.

## Tech Stack
- **Frontend**: Angular 19, standalone components, Signals, Reactive Forms
- **Backend**: Node.js, Express, Neo4j Aura
- **Database**: Neo4j Aura Free tier (no APOC plugin)
- **Testing**: Playwright for E2E tests

## User Preferences
- When restarting Node/bun processes: use specific PID, not `pkill node` or `Get-Process node | Stop-Process`
- Run processes in background so terminal stays free
- Use Windows PowerShell compatible commands

- Use `substring(randomUUID(), 0, 12)` instead of `apoc.math.randomLong()` for account numbers
- Neo4j integers need `neo4j.isInt().toNumber()` conversion

## Features Implemented
1. **Authentication**: Login and Registration with JWT
2. **Netbanking Dashboard**: Accounts, Transfers, Transactions
3. **Account Creation**: Create SAVINGS, CURRENT, or FIXED accounts
4. **Transaction Details**: Clickable modal with full transaction info
5. **Reactive Forms**: Full validation on all forms
6. **Toast Notifications**: Success/error feedback
7. **Loading States**: Visual feedback during async operations
8. **Playwright E2E Tests**: auth.spec.ts, netbanking.spec.ts
