## Common Issues & Fixes

| Issue | Solution |
|-------|----------|
| "Invalid Date" on transactions | Convert Neo4j datetime to ISO string in backend |
| Account numbers not generating | Use `substring(randomUUID(), 0, 12)` instead of APOC |
| Neo4j integers as objects | Use `neo4j.isInt().toNumber()` |
| Import path errors | Use relative paths like `../../services/api` |
